# 🇺🇸 English

## 📖 What is this project?

This project is a practical tutorial on **Clustering Techniques** in **Unsupervised Machine Learning**, implemented in Python through a Jupyter Notebook.

The notebook explores two fundamental clustering algorithms using the classical **NCI60 gene expression dataset**, widely used in bioinformatics and machine learning research.

---

## 🚀 Contents

- Introduction to Unsupervised Learning
- Clustering Fundamentals
- Data Preprocessing
- **PCA (Principal Component Analysis)**
- **K-Means Clustering**
- **Hierarchical Clustering**
- Dendrogram Visualization
- Cluster Interpretation and Analysis

---

## 🧬 Dataset

### NCI60 Dataset

The **NCI60** dataset contains gene expression data from 60 human cancer cell lines, including:

- Leukemia
- Breast Cancer
- Melanoma
- Colon Cancer
- Renal Cancer
- Lung Cancer
